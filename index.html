Features

What is in
the iOS app

The same surfaces you open after sign-in: Home, Train, Library, Profile, plus Team if you coach. Chat is the AI, not a Home card.

Combined rating

Home shows a backend-calculated rating. Tap the hero to open Assessment Hub: Skills (four areas) and Shot Mastery.

Goals

Set and track goals on Home. Chat can create a goal from the conversation. Progress updates from sessions, not from a marketing score.

Train

One Hybrid Hero: type a focus, pick suggestion chips, set 30 / 60 / 90 / 120 minutes, then Start session. Or build from scratch. Notes and your coaches sit below.

Chat: Coach PATH

A FAB on every screen. Players talk to Coach PATH. Coaches talk to Pickle. Actions (start a drill, draft feedback) come from the conversation, not a daily insight card.

Library

Warmup, Drills, Games, Stretching, Technique Videos, and Mindset. Same catalog for players and coaches. Favorites and add-to-session feed Train.

Coaches and Team

Players find and connect with a coach from Home or Train. Coaches get a Team tab for roster, player detail, reassessment, and 1:1 / group / clinic sessions.

How It Works

The loop
assess · train · reassess

A quiz-only profile gets a general session. Add Skills, then Shot Mastery, and Train chips get more specific.

1

Assess

Onboarding quiz, then Assessment Hub. Four skill areas plus Shot Mastery. Home shows the combined rating the backend returns.

2

Train

Open Train, pick a chip or type a focus, start a session. Browse Library for drills or a 3–15 minute mindset module. Ask Coach PATH if you are stuck.

3

Reassess

Finish the session checklist. Home and Goals update from that work. When it is time, reassess so the next session uses the new scores.

Two Paths

A player path and a coach path

One app, one active persona. Switch roles when you need to. AI handles the busywork; humans keep the relationship.

Player path

Assess, train, set goals, and talk to Coach PATH. Connect a human coach when you want someone on the court with you.

  • Tabs: Home, Train, Library, Profile
  • Combined rating + Assessment Hub
  • Goals on Home; Train Hybrid Hero
  • Chat FAB: Coach PATH
  • Find and connect with a human coach

Coach path

Same Train and Library as players, plus Team. Ask Pickle to draft feedback or prep. You still take attendance and write the notes that matter.

  • Tabs: Home, Train, Team, Library, Profile
  • Roster, player detail, suggest reassessment
  • 1:1, group, or clinic sessions
  • Attendance, shared notes, private notes
  • Chat FAB: Pickle (player context picker)
